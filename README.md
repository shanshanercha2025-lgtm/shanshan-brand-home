# 山山而茶品牌主页

打开 `dist/index.html` 即可本地浏览。图片、样式和交互均包含在项目中，不需要安装依赖。

开发预览：在此目录运行 `node server.mjs`，打开 `http://localhost:4173`。

页面包含：首屏五张茶礼影像点击循环切换、优先呈现的茶礼专区、品牌故事、随滚动渐显与影像位移、茶礼及茶品详情弹窗、喝茶方式、生活影像及品牌搜索指引。支持桌面与手机，并尊重系统减少动画设置。

2026-11-21 更新：首屏首先展示桂花茶扎染礼盒，其后依次为「马上 HAPPY」新年糯米普洱茶礼、滇红大金针罐装茶礼、桂花茶礼细节及蓝染随行茶礼。新增的四张品牌图片均已纳入页面；茶礼专区移动至首屏之后，日常茶品仍保留在后续内容。

已检查 1440×900 桌面及 390×844 手机尺寸，验证翻图、菜单、锚点导航、详情弹窗及关闭；未发现图片加载错误与控制台脚本错误。

素材来自当前山山而茶工作目录。商品价格、购买链接和联系方式未提供，页面引导访问者在小红书或微信小店搜索品牌名。
